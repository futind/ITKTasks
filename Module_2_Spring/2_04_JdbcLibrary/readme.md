# JDBC Library
## Task
### Overview
The task was to implement a simple service to manage book 
using Spring Data JDBC and `JdbcTemplate` in particular.

### Entities
Create an entity `Book`:
- `id` - autogenerated
- `title` - book's title
- `author` - book's author
- `publicationYear` - the year book was published in

### Services
Create a simple structure containing of a controller, 
service and a repository (using Spring Data JDBC) to provide 
basic CRUD functionality.

### Endpoints
- `GET /api/v1/books` - list all books
- `GET /api/v1/books/{bookId}` - list info about a particular book
- `POST /api/v1/books` - create a new book
- `PATCH /api/v1/books/{bookId}` - update info about a certain book
- `DELETE /api/v1/books/{bookId}` - delete a particular book

## Launch
At first, you would need to create/update .env file. An example of an env file:
```shell
# APPLICATION CONFIGURATION
APP_PORT=8080
APP_PORT_INTERNAL=8080

# DATABASE CONFIGURATION
DB_HOST=book-library-db
DB_NAME=book_library_db
DB_PORT=5433
DB_PORT_INTERNAL=5432
DB_USER=user
DB_PASSWORD=password
DB_URL=jdbc:postgresql://${DB_HOST}:${DB_PORT_INTERNAL}/${DB_NAME}
```


To launch the application run:
```shell
docker-compose build
docker-compose up -d
```
