# Spring Data Projections
## Task
### Overview
The task was to develop an application to manage employees in a company
(and to work with **Projections** in Spring Data).

### Entities
First entity is an `Employee` entity which contains the information about the employee:
- `id` (autogenerated) - PK
- `firstName`
- `lastName`
- `position`
- `salary`
- `department` - FK

Then, the `Department` is a simple entity which has the following fields:
- `id` (autogenerated) - PK
- `name`

To use the **projections** functionality it was necessary to create an interface
`EmployeeProjection` with methods:
- `getFullName()` - to get the full name of an employee
- `getPosition()` - to get employee's position
- `getDepartmentName()` - to get the name of the department an employee works in

Alas, I was to implement repositories for aforementioned entities and create
basic CRUD functionality in the form of RESTful endpoints.

### Endpoints
List of the employee-related endpoints:
- `GET /api/v1/employees` - get the data of all employees
- `GET /api/v1/employees/projection` - get the projections of all the employees' data
- `GET /api/v1/employees/{employeeId}` - get the information about a particular employee
- `GET /api/v1/employees/{employeeId}/projection` - get the projection of the data of a particular employee
- `POST /api/v1/employees` - create a new employee
- `PATCH /api/v1/employees/{employeeId}` - update the information of a certain employee
- `DELETE /api/v1/employees/{employeeId}` - delete the information about an employee

List of the department-related endpoints:
- `GET /api/v1/departments` - get all departments
- `GET /api/v1/departments/{departmendId}` - get info about a particular department
- `POST /api/v1/departments` - create a new department
- `PATCH /api/v1/departments/{departmendId}` - update the info about a certain department
- `DELETE /api/v1/departments/{departmendId}` - delete the info about a certain department

## Launch
In order to launch the application you would need to configure it at first.
Create/edit the `.env` file in the root of the repository.

An example of the `.env` file:
```shell
# APP
APP_PORT=8080
APP_PORT_INTERNAL=8080

# DB
DB_PORT=5433
DB_PORT_INTERNAL=5432
DB_NAME=projections_db
DB_HOST=projections-db
DB_USER=secret
DB_PASSWORD=secret
DB_URL=jdbc:postgresql://${DB_HOST}:${DB_PORT_INTERNAL}/${DB_NAME}
```

Then you would be able to launch the applcation using the following commands:
```shell
docker-compose build
docker-compose up -d
```
